### ⚠️ Требует реализации

#### Windows (`src/windows.rs`)
- ✅ Базовая структура
- ✅ Получение списка аудио сессий через WASAPI
- ❌ Реальный захват аудио данных через `IAudioCaptureClient`
- ✅ Передача PCM данных через канал

#### macOS (`src/macos.rs`)
- ✅ Базовая структура
- ✅ Получение списка приложений через `ps`
- ✅ Генерация тестового сигнала для проверки интеграции
- ✅ Передача PCM данных через канал
- ❌ Реальная реализация через ScreenCaptureKit (macOS 13+)
- ❌ Альтернатива через виртуальный драйвер для старых версий

#### Linux (`src/linux.rs`)
- ✅ Базовая структура
- ❌ Реализация через PulseAudio API
- ❌ Поддержка PipeWire
- ❌ Получение списка sink-input по PID
