# WebRTC Desktop Client

Десктопное приложение WebRTC для Windows, Linux и macOS на базе Electron и Vue.js.

## Требования

- Node.js 20.19.0+ или 22.12.0+
- Бэкенд API (например, из этого репозитория) должен быть запущен (по умолчанию `http://localhost:3000`)

## Установка

```bash
npm install
```

## Запуск в режиме разработки

Соберите главный процесс Electron и запустите приложение с горячей перезагрузкой Vue:

```bash
npm run electron:dev
```

Или только фронтенд (без Electron) для отладки в браузере:

```bash
npm run dev
```

## Сборка под платформы

- **Windows:** `npm run build:win`
- **macOS:** `npm run build:mac`
- **Linux:** `npm run build:linux`

Артефакты появятся в папке `release/`.

## Конфигурация API

Укажите URL бэкенда в файле `.env`:

```
VITE_API_URL=http://localhost:3000
```

## Функциональность

- Авторизация и регистрация
- Список каналов (комнат), создание и выбор
- Голосовые/видео звонки через WebRTC
- Демонстрация экрана
- Текстовый чат по каналам
- Выбор камеры и микрофона
